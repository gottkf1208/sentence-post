문장 우체국 v0.5 · 내 기기 PDF 판

3·4·5·6학년 각각 365개, 총 1,460개 실제 교과서 원문 범위와 연결합니다.
원문 PDF·추출 본문은 배포 파일에 들어 있지 않습니다.

시작하기
1. Chrome 또는 Edge에서 문장우체국.html을 열거나 https://gottkf1208.github.io/sentence-post/ 에 접속합니다.
2. 선생님 책상에서 학년을 고르고 ‘이 기기의 교과서 PDF 연결’을 누릅니다.
3. 지원 파일명과 같은 공식 PDF를 선택합니다. 여러 권을 한 번에 선택할 수 있습니다.
4. 오늘의 편지에서 DAY 1–365와 필사 분량을 고르고 인쇄합니다.
5. 학생에게 QR과 종이 교과서/학습지를 함께 줍니다. 학생은 자기 기기에 필사 사진과 생각을 저장합니다.

무엇이 들어 있나요?
- 3학년 365개 / 4학년 365개 / 5학년 365개 / 6학년 365개
- 학년별 1학기 183개 + 2학기 182개. 학습 진도에 맞게 자유롭게 고릅니다.
- 국어 가·나 16권, 3·4학년 국어활동 4권. 2022 개정 5·6학년은 별도 국어활동이 없습니다.
- 원문에 있는 낱말 197종, 활동별 낱말 풀이와 생각 질문
- 동일 범위의 짧게/보통/길게 분량은 별도 활동으로 세지 않습니다.
- 기존 100종 수집첩·사진 노트·백업을 유지합니다.

원문과 분량
PDF에서 해당 범위를 이미지로 읽으므로 원문의 글자와 띄어쓰기를 다시 쓰거나 AI가 바꾸지 않습니다.
365개는 서로 다른 발췌 범위입니다. 365개의 독립 작품이나 하루마다 새 낱말 365종이라는 뜻은 아닙니다.
범위는 자동 선별하고 원본 위치·중복·낱말 포함 여부를 검사했습니다. 모든 범위를 사람이 교정한 것은 아닙니다.
수업 전 ‘교과서 전체 페이지 대조’에서 문맥과 분량을 확인해 주세요. 짧은 글은 분량 버튼이 같은 글자 수일 수 있습니다.
DAY를 연속 진행하면 활동 시간을 늘릴 수 있습니다. 인쇄는 원문 읽기 면과 필사·어휘·생각 면으로 나뉩니다.

기기에 보관하기
PDF와 사진을 서버에 전송하지 않습니다. 브라우저의 IndexedDB에 저장합니다.
책 20권 전체는 약 3.5GB이므로 담당 학년의 필요한 책부터 연결해 주세요.
공간이 부족하면 PDF는 이번 창에서만 사용하며 연결 결과에 안내합니다.
사진 백업에는 PDF가 포함되지 않습니다. 기기를 바꾸면 PDF를 다시 연결해 주세요.
기기·브라우저·접속 주소가 바뀌면 보관함도 다릅니다. 브라우저 데이터 삭제 전에 사진 백업을 저장하세요.
학생 QR은 활동 ID와 분량만 전달합니다. 교사의 PDF나 사진은 전송하지 않습니다.

판본 확인
선생님 책장에 표시한 파일과 SHA-256이 일치할 때만 원문을 엽니다.
같은 제목이어도 다른 판본/수정본이면 페이지가 달라질 수 있어 연결을 거절합니다.
그런 경우 기존 ‘원문 직접 등록’ 기능을 사용할 수 있습니다.

판매 구성
배포 대상은 프로그램·활동 연결 정보·직접 제작한 그림입니다.
교과서 PDF와 원문 본문은 포함하지 마세요. 사용자가 준비한 PDF도 해당 자료의 이용 조건에 맞게 사용해야 합니다.
PDF 렌더러는 Mozilla PDF.js 6.5.438(Apache-2.0)이며 라이선스 파일을 함께 제공합니다.
