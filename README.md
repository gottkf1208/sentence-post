# 문장 우체국

초등 3~6학년을 위한 필사·어휘 활동 프로그램 v0.3입니다.

[프로그램 열기](https://gottkf1208.github.io/sentence-post/)

- 창작 예문 365편과 날짜별 추천, 주제·낱말 검색
- 짧게 1편 / 보통 3편 / 길게 5편의 주제별 묶음 분량 선택
- 교사 문장 편집, 학습지 인쇄, 활동 QR 및 파일 공유
- 캔디 우체국 / 모험 우편단 수집첩
- 필사 사진과 답안은 학생 기기의 브라우저에 저장하며 서버로 전송하지 않습니다.

## 보관 안내

사진과 기록은 기기·브라우저마다 별도로 보관됩니다. 정기적으로 보관함 백업을 저장하세요. 기존 로컬 파일에서 웹 버전으로 옮길 때는 백업을 내보낸 뒤 웹 버전에서 가져오세요.

## 배포

GitHub Pages의 `main` 브랜치 루트에서 `index.html`을 제공합니다. 프로그램과 그림이 포함된 단일 HTML 배포본입니다. 기본 예문은 창작글이며 교과서 원문이 아닙니다.

외부 라이브러리의 라이선스는 `THIRD_PARTY_LICENSES.txt`를 참고하세요. 해당 고지는 포함된 외부 라이브러리에 관한 것이며 프로젝트 전체에 대한 오픈소스 라이선스 부여를 뜻하지 않습니다.
