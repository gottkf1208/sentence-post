# 문장 우체국 v0.4

종이에 필사하고 사진을 기기에 저장하는 초등 국어 활동 도구입니다.

- 서로 다른 캐릭터 100종과 10개 테마 도감
- 교과서 원문·학년·학기·단원·쪽수 입력 및 원문 파일 가져오기
- 원문을 다시 쓰지 않고 연속된 문단 범위로 필사 분량 선택
- 인쇄 학습지, QR/활동 파일 전달, 사진 노트, 백업·복원
- 학생 로그인과 사진 업로드 서버 없음. 사진은 사용한 브라우저의 IndexedDB에 보관

현재 배포에는 검증된 교과서 기본 지문이 포함되어 있지 않습니다. 이전 창작 지문은 기본 목록에서 제외했습니다. 교과서 원문 수집·대조 작업이 진행 중이며, 교사는 사용 가능한 원문을 입력하거나 원문 묶음을 가져올 수 있습니다. ‘원문 확인’은 입력자의 대조 확인이며 자동 진위 판정이 아닙니다.

브라우저 데이터 삭제 시 기록이 사라질 수 있으므로 정기적으로 백업하세요. 다른 기기로 자동 동기화되지 않습니다. 같은 작품의 분량만 바꾸어 다시 제출해도 도감 보상은 중복 지급되지 않습니다.
